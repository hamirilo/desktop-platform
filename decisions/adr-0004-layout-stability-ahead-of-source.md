# ADR-0004: 「表示を切り替えても操作の位置を変えない」を、出どころの実装より先に UI Standard へ入れる

**状態**：採用
**日付**：2026-10-14

## 状況

stockroom では、表示を切り替えるたびに操作の位置が変わる。

- フォントの「見本」から「リスト」へ切り替えると、見本の文字の行が消えてツールバーが 1 行縮む
- グループ分けで「ファミリー」を選んだときだけ「まとめる／並べる」が出て、ほかを選ぶと消える
- 開いている表示（ゴミ箱、重複の候補、スマートフォルダ、フォルダ）によってツールバーの項目が増減し、「評価」の位置が毎回変わる

手が覚えた場所を毎回探し直すことになり、使いにくい。持ち主は、stockroom だけでなくこの Platform を使うすべてのツールで同じにしたい。

一方で [ADR-0003](adr-0003-core-and-optional-standards.md) は「Standard の各節は出どころとして stockroom / Shelf の実装を指す。指せないルールは Standard に書かない」と決めている。このルールはまだどのツールにも実装されていないので、そのままでは Standard に書けない。

## 決定

[UI Standard](../standards/ui.md) §10「レイアウトの安定」として今入れる。出どころは当面、stockroom の [`docs/UI.md`](https://github.com/2204601/stockroom/blob/main/docs/UI.md)（原則と、直す箇所の一覧）を指す。

ADR-0003 の「出どころを指せないルールは書かない」の例外は、このルール 1 件に限る。

## 理由

- ずれは新しい画面を作るたびに生まれ、あとから直すと手戻りになる。作る段階で避けられるよう、先に書いておきたい。
- ルールの中身は stockroom で実際に困った事例から来ており、机上の好みではない。直す箇所も `docs/UI.md` に特定してある。

退けた選択肢：

- **stockroom で直してから昇格する**：ADR-0003 どおりだが、直し終わるまでに作る画面や Shelf の画面がルールの外に置かれる。
- **ADR-0003 の基準そのものを広げる**（操作感のルールは出どころ無しでも Standard にしてよい、とする）：好みの話を Standard に入れない、という ADR-0003 の利点が崩れる。例外を 1 件に留めるほうが基準を保てる。

## 影響

- **Adopt going forward**：新しく作る画面、手を入れる画面から §10 を守る。
- stockroom は `docs/UI.md` の一覧に沿って順に直す。Shelf は画面に触れるときに確認する。

## 見直す条件

- stockroom で一覧の箇所を直したら、§10 の出どころを実装のファイルへ差し替え、この ADR に「出どころを実装へ差し替えた」と追記する。
- 2 つ目のツールで当てはまらない場面が繰り返し出たら、Standard から外してツール固有の判断に戻すかを検討する。
